Copy scheduler_clustered/ and run_clustered_comparison.py into the PROPER root.

Run both optimisations and the common-sample paired validation:
    python run_clustered_comparison.py

Use existing root-level scheduler results and rerun only validation/plots:
    python run_clustered_comparison.py --reuse-results

Default outputs:
    outputs/clustered_comparison_runs/run_<timestamp>/

See README_PAIRED_COMPARISON.md for validation definitions and options.
