Copy the complete scheduler_clustered/ directory into the PROPER repository
root, alongside scheduler/ (or the historical optimizers/ package).

Requirements:
    gurobipy with a valid Gurobi licence
    numpy, pandas, matplotlib

Run the deterministic + CVaR optimisation and paired validation:
    python -m scheduler_clustered.run_cluster_comparison \
        --config config/conf_IEEE24_scheduler_v2.json

Reuse existing optimisation JSON files and rerun validation/plots:
    python -m scheduler_clustered.run_cluster_comparison --reuse-results

Default outputs:
    outputs/clustered_comparison_runs/run_<timestamp>/

See scheduler_clustered/README.md for the formulation, configuration fields,
Gaussian load model, and interpretation of the CVaR risk-reduction guardrail.
